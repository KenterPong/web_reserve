# 首頁改版規格 v2（www.mybookdate.com）

## 改版目標
1. 擴大目標職業族群（不限美髮師）
2. 讓陌生工作者看到首頁後覺得「這說的是我的問題」
3. 降低信任門檻（先體驗顧客端，不需要登入）
4. 改善 SEO 定位

---

## 平台定位

**目標族群（第一波）**
美髮師、美甲師、美睫師、按摩師／整復師、寵物美容師

**核心訴求**
不需要 LINE 官方帳號，3 分鐘建立專屬預約頁面，顧客點連結即可預約。
